# skills

Personal collection of Agent Skills, installable via [skills.sh](https://skills.sh):

```
npx skills add idanlevin/skills
```

Or install a single skill:

```
npx skills add idanlevin/skills/pyramid-summary
```

## Skills

- **pyramid-summary** — summarize text using Barbara Minto's Pyramid Principle (answer-first executive summary with supporting ideas).
